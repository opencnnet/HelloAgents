流式事件是怎么工作的？
6 条消息 · 今天 14:30
原项目里的 SSE 流式输出是怎么组织的？事件都包含哪些字段？
14:30
H

HelloAgents 的流式输出基于 StreamEvent 序列：运行器把 Agent 循环中的每个阶段包装成事件，再通过 to_sse() 转成 SSE 帧推送给浏览器。

一帧事件的结构固定为四段：

  • type — 事件类型，如 llm_chunk、tool_call_start
  • timestamp — 数值时间戳
  • agent_name — 产生事件的 Agent
  • data — 事件负载，字段随类型变化

真正的前端接入只需要一个能按帧边界切分的解析器：

python
async for event in stream:
    if event.type == StreamEventType.LLM_CHUNK:
        print(event.data["chunk"], end="")
    elif event.type == StreamEventType.AGENT_FINISH:
        # 最终答案取 result，而不是拼接所有文本
        final = event.data["result"]
注意：最终答案应读取 agent_finish.data["result"]，中间片段可能是初稿、评审或计划步骤。

拼接文本只是展示用的“草稿流”，而 result 是运行器确认的终稿。以 ReAct Agent 为例，循环里可能经历了多个工具回合，每个回合都会产生新的 llm_chunk；只有 agent_finish 才代表整个任务结束。
